# Student Management System

## Project Description

A Student Management System developed using Java, SQL, and JDBC to manage student records efficiently.

## Features

- Add student records
- View student records
- Update student records
- Delete student records
- Search student records

## Technologies Used

- Java
- SQL
- JDBC
- MySQL

## Concepts Used

- Object-Oriented Programming
- CRUD Operations
- Database Connectivity
- Exception Handling
